# 2026-11-19 — cwebserv 마무리 + 구성도

## Bugs found while writing the atlas (all with regression tests)
- CGI child inherited the worker's blocked SIGINT/SIGTERM mask through execve (and SIG_IGN for SIGPIPE). Fix: child resets with sigprocmask(SIG_SETMASK, empty). Test: cgi-bin/signals.sh → "SIGTERM delivered".
- CGI timeout killed only the shell; grandchildren (sleep) were orphaned. Fix: setpgid in child+parent, kill(-pid, SIGKILL). Test: pgrep '^sleep 37' == 0 after 504.
- Added X-Content-Type-Options: nosniff on typed responses; tests for it and octet-stream fallback.
- `make test` used to run only unit tests; now unit + functional (+edge). Added `make memcheck`.

## Facts checked against source (easy to misstate)
- Head limit is HTTP_MAX_HEAD = 8 KB URI + 16 KB = 24 KB total, 64 headers; no separate 16 KB header cap.
- MAX_BACKENDS 16 per upstream; TUNNEL_IDLE_MS 30000; cgi_timeout 5000 ms; fail_timeout 10 s.
- Access log timestamp format "%Y-%m-%d %H:%M:%S"; info/error go to stderr.
